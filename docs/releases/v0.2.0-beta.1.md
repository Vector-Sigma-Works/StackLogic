# StackLogic v0.2.0-beta.1

Release date: 2026-07-25

Public URL: https://vector-sigma-works.github.io/StackLogic/

## Summary

This beta minor release adds StackLogic's theme system and the first accepted Matrix experience while preserving gameplay geometry and pacing. Players can select Default, Matrix, CandyPop, or Dark from the title screen and can change themes while paused without restarting or resuming the game.

## User-visible changes

- Four persistent themes: Default, Matrix, CandyPop, and Dark.
- Matrix rain behind the game and UI, with input-safe stacking.
- Solid Matrix pieces in deterministic green shades.
- Solid Dark pieces in deterministic black-to-grey shades.
- Theme selection in a dedicated pause menu.
- Accessible Arrow-key and Home/End theme navigation with synchronized roving focus.
- Wide touch-device controls for iPad-class landscape and portrait viewports.
- Reduced-motion behavior that creates no Matrix rain animation resources and stops/restarts rain when the preference changes live.

## Compatibility and data

- No gameplay board geometry, timing, scoring, or save-format migration is introduced.
- Existing local high scores and preferences remain in browser localStorage.
- No runtime dependency was added for the theme or rain implementation.

## Known limitation

Web applications cannot directly observe whether an iPad hardware keyboard is docked. On-screen controls use the standards-based `(hover: none) and (pointer: coarse)` input-capability proxy. Automated iPad-class viewport emulation passes; physical Safari behavior remains a hardware/browser acceptance boundary.
