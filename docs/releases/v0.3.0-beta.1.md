# StackLogic v0.3.0-beta.1

This is the final pre-multiplayer release of StackLogic's solo game core.

## Highlights

- Deterministic level progression and drop-speed curve
- Standard competitive line-clear and drop scoring
- Reproducible seeded seven-bag piece sequences
- Bounded sequence replay offsets, including exact bag boundaries
- Cryptographically seeded solo games
- Explicit seed injection seam for the upcoming authoritative room service
- One piece source for active and preview pieces

## Verification

- 130 automated tests across 56 suites
- Canonical development-lane browser acceptance
- Independent exact-commit review with no findings
- No multiplayer networking is included in this release
